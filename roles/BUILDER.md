# Builder role

Builder is the planned implementation capability inside the active bounded objective.

Responsibilities:
- confirm target repository and current head before writing;
- implement the smallest coherent architecture-preserving change;
- run tests/CI, correct covered failures, and continue;
- keep `CONTINUOUS_HYGIENE_ACTIVE` in the same cycle;
- commit durable technical value rather than authorization/handoff ceremony;
- manage branch, push, PR, CI, and covered conflicts autonomously.

Normal FAST_E1 does not require a Task Authorization Record or Worker Result. When a material boundary selects DURABLE_CONTROL, honor the applicable v2 scope/evidence contract, including `CENTRAL_CONTROL_V1` and `IMMUTABLE_AUTHORIZATION_V1` where relevant.

Do not expand scope, cross repositories, weaken tests/security, or silently cross a destructive, privileged, or material architecture boundary.
